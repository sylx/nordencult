傭兵システムと放浪状態の騎士について

# 傭兵とは

このゲームでは勢力に所属する騎士の率いる正規軍の他に、金銭で契約し戦う傭兵が存在する。

傭兵とは、騎士データのうち、傭兵フラグのついた騎士のことを言う。
傭兵は独自のパラメーターとして以下を持つ

- 契約金（月額は契約金の1/6として計算する）
- 最大兵力（～1000)
- プライド値（高いほど、傭兵業界の友好度によって態度が変化する1～5）
# 傭兵の契約

傭兵は、契約金ならびに月額課金の契約を行うことで雇うことができる。月額金を支払い続ける限り傭兵は雇用し続けることができるが、6ヶ月を目安にランダムで契約更新料を要求されることがある。
傭兵の契約は都市のコマンドで行い、契約が成立すると、都市の騎士一覧に傭兵が含まれる。

## 無雇用状態の傭兵

どの勢力からも雇われていない傭兵は、マップ上を自由に移動しており、常にどこかの拠点に存在する。

- 傭兵は、進行フェーズのたびに移動する（隣接の拠点のどれか）か留まるかをランダムで決定する

## 契約可能な傭兵

その都市から契約可能な傭兵は、

- 酒場がない場合
	- 雇用できない（傭兵コマンドが使えない）
- 酒場がある場合
	- その都市＋1hopの都市に在住している傭兵
- 傭兵ギルドがある場合
	- その都市＋2hopの都市に在住している傭兵

というふうに都市施設によって異なる。傭兵が在住している拠点の支配権は雇用できるかに無関係であり、敵拠点にいる傭兵も雇用することが可能である。

## 傭兵の選り好み

プライド値の高い傭兵は雇われる勢力を選ぶので、契約できる金銭を所持していても、雇うことができない。

- 仕様としては、外交関係の一種として傭兵業界との友好度が存在しており（これは外交画面では表示されない）、傭兵との契約を繰り返したり、酒場、傭兵ギルドを所持することで増加する。
	- 逆に、（後述するが）回復中の傭兵との契約を打ち切ったり、傭兵を全滅させたりすることで悪化する。
- 傭兵業界の友好度が高い場合、契約金や月額金のディスカウントをうけることができ、逆に、悪い場合は、釣り上げられる。

# 傭兵の独立採算

- 通常、部隊の兵数は侵攻時の編成によって決定されるが、傭兵はその対象にならない
- 傭兵の兵数は騎士に付属する情報として保持され、出撃時にも都市の兵を消費しないし、都市の兵を使って回復することもできない。
- 戦闘によって、兵数が減った傭兵の兵力は最大値の10%が毎ターン回復する
- 兵力が減った状態で契約が切られた傭兵、または全滅した傭兵は、傭兵市場から姿を消し、「回復中」の状態になり、兵力の最大値の10%が毎ターン回復する。
- 回復中の傭兵も拠点を移動する。
- 回復が完了した傭兵は再び市場に登場する

# 戦略画面における傭兵の扱い

- 傭兵は、内政の担当官になることができない。同様に領主になることもできない
- 傭兵は移動コマンドで拠点を移動することができる。ただし、領主になることはできない。（領主のいない拠点に傭兵が移動しても、領主は不在のままである）
- 移動対象に傭兵が含まれる場合、単騎移動は選択できない。その場合、単騎移動のチェックボックスのツールチップに「傭兵は単騎移動できません」と表示する
- 傭兵だけが存在し、領主のいない都市が攻撃された場合、傭兵は近くの都市に撤退する。撤退する拠点が存在しない場合、傭兵の契約は強制解除され、傭兵は未雇用状態になる
- 傭兵は輸送の担当官になることができる

# 編成時の傭兵の扱い

- 傭兵は侵攻、防衛の編成時に出撃することができる。
- 「傭兵の独立採算」で述べたとおり、ユーザーは傭兵の兵数を変更することができない
- 傭兵は軍団長になることができない

# 戦闘時の傭兵の扱い

- 傭兵は通常の部隊と同様にユーザー操作可能である
- 傭兵は捕縛されない。退却は必ず成功する
	- 退却先がない場合、傭兵は退却できない
	- 退却先がない傭兵が全滅した場合、傭兵の契約は解除される（全滅しているので回復中状態になる）

# 戦後処理における傭兵の扱い

- 領主がいない場合など、自動敗北したケースでは、単に傭兵の契約は解除される
- 傭兵が退却した先に領主が存在しないケースでも傭兵は領主にならない

# 放浪の騎士

- 勢力が滅亡することで、在野状態になった騎士は、最後の拠点を在住として「放浪」状態になる。
- 放浪状態の騎士は傭兵と同様に各地を移動する
- 放浪状態の騎士は探索またはランダムイベントで登用することが可能（探索の実装時に実装すること）
- 放浪状態の騎士は、自分を滅ぼした勢力を「怨恨勢力」として覚えており、自分を滅ぼした勢力に登用されることはない（ランダムイベント自体が発生しない）
- 放浪状態の騎士の一覧を見ることはできない
	- デバッグコンソールで確認することは可能にする

## 最初から放浪している騎士

- 騎士データで、勢力が設定されていない騎士も放浪状態としてスタートする
	- 怨恨勢力の設定をnorden-dataで可能にすること
