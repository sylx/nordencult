# M002: 内政（都市の成長）

都市に騎士を担当として常駐させ（三國志IV方式）、毎ターンの自動処理で金・物資・兵士・人口が増え、施設を建てて都市が育っていく。その一巡と、侵攻（M001）との行き来を最低限の実装で通す。

複数のセッションで進めるための作業メモを兼ねる。タスクを終えたらチェックを付け、決めたことは「決定事項」、セッションの記録は末尾の「作業ログ」に追記する。

## 完了条件（通しのデモ）

1. 第1ターンの都市コマンド画面で、フルーエン（P012）の人口・Tier・商業・生産・備蓄物資・兵数・練度・施設スロットの使用数・代官が見える。HUD に勢力の金が出る
2. 「内政」→ 内政画面。フルーエンの騎士を代官（1人）と軍事担当に割り当て、能力に応じた補正の見込み（商業 +x% など）が出る
3. 同じ画面で施設を選んで着工する。金が引かれ、建設中の進捗（投入済み / 必要な物資）と完成までのターン数の見込みが出る
4. 「募兵」で兵を足すと、兵数が増え練度が下がる
5. 「ターン終了」→ 行軍フェーズ → 第2ターン。金が商業の合計だけ増え（俸禄が引かれ）、建設が進み、練度が上がり、人口が増える
6. 第2ターンにフルーエンを開くと、前のターンから変わった数値が演出つき（増分の表示・カウントアップ）で確かめられる
7. 何ターンか進めると施設が完成してスロットに入り、効果が出力に乗る。人口が閾値を超えると Tier とスロット数が上がる（デバッグで人口を足して確かめてよい）
8. 代官・軍事担当の騎士を侵攻画面で選ぶと「担当を外して出撃」になり、予約すると担当が外れる。予約を取り消すと担当に戻る
9. 侵攻に出した兵は出発した都市の兵数から引かれ、物資と金を消費する。戦後、兵は騎士と一緒に入城・帰還する
10. CPU 勢力の都市も同じ処理で育つ（担当は初期の領主が代官になるだけ）

## スコープ

含む:

- 都市の状態（人口・備蓄物資・兵数・練度・施設・建設中・担当）と、勢力の金
- 都市のマスターデータの刷新（`agriculture` の廃止、初期値の追加）と norden-data の拠点エディタの対応
- 施設のマスターデータと norden-data の施設エディタ（画像の管理を含む）
- 毎ターンの内政処理（担当の補正 → 金 → 物資と建設 → 兵士と練度 → 人口と Tier）と、その結果の記録（演出用の差分）
- 担当の割り当て・解除、建設の着工・中止、募兵
- 侵攻との兼ね合い: 担当の騎士の出撃、出撃で兵数・物資・金を消費、戦後の兵の移動
- 輸送の基盤（状態の操作関数とテストまで）
- norden-ui: 都市概要の表示、内政画面、成長の演出、侵攻画面での担当の表示

含まない（後続のマイルストーン）:

- 輸送の画面（M002 は操作関数だけ）
- CPU の思考（担当の割り当て・建設・募兵をしない。初期の代官のまま自然に育つだけ）
- 研究・探索・商人（購入・売却）のコマンド
- 金が足りないときの罰（俸禄の未払い・離反など）。M002 は金がマイナスにならないよう操作を止めるだけ
- 傭兵の出現の効果（施設の効果の種類としてだけ持つ）
- 戦闘での兵の損耗の反映（battle 側が残兵を返せるようになったら。下記「兵の出入り」）
- 人口の減少・Tier の降格、食料の概念
- セーブ・ロード、勝利・敗北条件

## 決定事項

| 項目 | 決定 |
| --- | --- |
| マスターと状態の分け方 | M001 と同じく、都市のマスターデータ（`src/data/city.ts`）は初期値だけを持ち、ターンで変わる値は `GameState.cities[cityId]`（`CityState`）に持つ。提案の `City` インターフェースのうち人口・備蓄・兵・施設・建設・担当は `CityState` 側、名前・種別・タグ・特性・基礎の商業と生産はマスター側 |

| 領主と代官 | 代官（`assignments.governor`）を都市の領主とし、`CharacterState.isLord` は廃止する。初期の領主（`characterStart.json` の `isLord`）を代官の初期値にする |
| 担当の数 | 代官は1人、軍事担当は都市の騎士なら何人でも（補正は逓減させる。下記）。1人の騎士は1つの担当だけ。担当できるのは所属している都市だけ |

| 内政処理のタイミング | 行軍フェーズを解決しきってから次のターンの戦略フェーズに入る直前に、全勢力の全都市をまとめて処理する（`runEconomy(state)`）。戦後の所属・騎士の移動が済んだ状態で計算する |
| 建設中の物資 | 建設中はその都市の生産をすべて建設に回し、備蓄には入らない。完成した余りは備蓄に入れる。備蓄から建設へ足す操作は M002 では作らない |
| 施設の中止 | 中止できる。投入済みの物資と金は戻らない |
| 同じ施設 | 1都市に同じ施設は1つ。建設中は1件だけ |
| 金の不足 | 着工・募兵・出撃は金が足りなければできない。俸禄は差し引いて0で止める（不足の罰は後続） |
| 1ターンの募兵 | 上限を数えるため `CityState.recruited`（このターンに募兵した数）を持ち、内政処理で0に戻す |
| 代官の補正の下限 | 能力が `ABILITY_BASE`（50）以下なら補正は0。マイナスにはしない（代官がいないのと同じ） |
| 軍事担当の募兵の補正 | 魅力から（訓練は統率から）。どちらも補正の大きい順に並べ、2人目以降は半分ずつ（割り当ての順に依らない） |
| 性格の補正（M002） | 代官だけ。合理主義 `pragmatic` 商業 +5%、厳格 `strict` 生産 +5%、寛容 `generous` 成長 +10% |
| 予約中の騎士の担当 | 出撃予約中の騎士は担当にできない（「出撃予約中です」） |
| 担当の解除（M002-25 を先に） | 騎士が都市を離れたら（入城・退却・在野）その都市の担当から外す。攻め落とされた都市の担当は空にする。帰還は同じ都市に戻るので担当はそのまま（予約での解除は M002-23） |
| 予約の兵数の上限（M002-24 を先に） | `soldierPool` を廃止し、出発都市の `troops` のうちこのターンにまだ予約していない分（`soldiersLeft`）にした。防衛軍も都市の `troops` を分ける。兵数を予約で実際に引くのは M002-24 |
| 中立の都市 | 内政処理で同じように育つ（金は勢力が無いので入らない） |
| 初期の金 | 全勢力 `INITIAL_GOLD`（500） |
| 着工とスロット | 建設中の施設はスロットを使わない扱いで、建設済みの数がスロット数未満なら着工できる（建設中は1件だけなので、完成時に溢れることはない） |
| 施設の画像 | 元画像は `norden-data/buildings/sources/` に置き、大きさに関わらずコミットしない（騎士の元画像と同じ）。使う元画像と正方形の範囲は `norden-data/buildings/images.json`（コミットする）。書き出しは 256×256 の webp |
| 地図の `CITY_LIST`（M002-12） | ルートの拠点データと同じ項目・値に揃える（`agriculture` を消し、`military` → `production`）。地図だけの `image` は残す。食い違いはルートの `src/data/city.test.ts` で検出する |
| 都市概要の表示（S4） | 代官（「領主」の欄を「代官」に）・人口と Tier・騎士、兵数・練度・物資（大きな数字で横に並べる。グラフにしない）、商業と生産（実効値のバーと、違うときだけ基礎値）、施設スロット。都市の概観の画像は外す（`CityView.art` も削除）。細かい装飾は別のセッションで（部品 `BuildingSlots`。建設済み・建設中の進捗と残りターン・空き）。騎士カードの注記は「代官」「軍事担当」 |

## 設計

### 状態

```ts
type CityTier = 1 | 2 | 3

interface CityConstruction {
  buildingId: string
  /** 完成に必要な物資（ハンマー）。着工時のマスターの値を写す */
  requiredSupplies: number
  investedSupplies: number
}

interface CityAssignments {
  governor?: CharacterId
  military: CharacterId[]
  // 研究・探索などの担当は後続で足す
}

interface CityState {
  population: number
  storedSupplies: number
  troops: number
  /** 0..MAX_MORALE */
  troopMorale: number
  /** 建設済みの施設（スロットの順） */
  buildings: string[]
  construction: CityConstruction | null
  assignments: CityAssignments
}

interface GameState {
  // …M001 のもの（cityMorale は消す）
  cities: Readonly<Record<CityId, CityState>>
  /** 勢力の国庫 */
  gold: Readonly<Record<FactionId, number>>
  /** 直前の内政処理の結果（演出用）。都市ごとの前後の値と出来事 */
  lastEconomy: EconomyReport | null
}

interface EconomyReport {
  turn: number
  /** 勢力ごとの金の収入・支出 */
  factions: Record<FactionId, { income: number; salary: number; before: number; after: number }>
  cities: Record<CityId, {
    before: CitySnapshot
    after: CitySnapshot
    /** 施設の完成・Tier の上昇など */
    events: EconomyEvent[]
  }>
}
```

`CitySnapshot` は人口・Tier・商業（実効値）・生産（実効値）・備蓄・兵数・練度・建設の進捗。都市概要の演出は `before` → `after` を見る。

マスター（`src/data/city.ts`）:

```ts
interface City {
  id: string; name: string; nameEn: string
  type: string; tags: string[]; special?: string
  belongTo?: string
  /** 初期値 */
  population: number
  /** 基礎の商業・生産（担当・施設の補正の前） */
  market: number
  production: number
  /** 初期値。省略時は既定値（下記） */
  storedSupplies?: number
  troops?: number
  troopMorale?: number
  buildings?: string[]
}
```

省略時の既定値（仮）: 備蓄 = 生産 × 2、兵数 = 生産 × 5（M001 の `soldierPool` と同じ）、練度 = 70（M001 の `INITIAL_MORALE`）、施設なし。

### 施設

```ts
type BuildingEffect =
  | { kind: 'marketPct'; value: number }       // 商業 +value%
  | { kind: 'productionPct'; value: number }   // 生産 +value%
  | { kind: 'growthPct'; value: number }       // 人口成長 +value%
  | { kind: 'trainingPct'; value: number }     // 訓練の上昇 +value%
  | { kind: 'recruitPct'; value: number }      // 1ターンに募兵できる数 +value%
  | { kind: 'recruitMorale'; value: number }   // 新兵の練度 +value
  | { kind: 'mercenary' }                      // 傭兵が現れる（M002 は効果なし）

interface Building {
  id: string
  name: string
  description: string
  /** 必要な物資（ハンマー）と、着工時に払う金 */
  supplies: number
  gold: number
  /** 建てられる最低の Tier */
  minTier: CityTier
  /** 都市にこのタグのどれかが要る（例: 港 → 港湾）。省略: どこでも */
  requiredTags?: string[]
  effects: BuildingEffect[]
  /** src/assets/buildings/ の画像 */
  image?: string
}
```

- マスターは `src/data/buildingData.json` と `src/data/buildings.ts`。norden-data の施設エディタが書く
- 画像は norden-data に元画像を置き、書き出しでゲームの `src/assets/buildings/<id>.webp` に縮小して書く（騎士の画像と同じ流れ）。元画像が大きければコミットしない
- 最初の施設は 6〜8 種（市場・工房・兵舎・訓練場・倉庫・港・神殿 など）。数値は仮

### 内政処理（`runEconomy`）

`src/game/economy/` に置く。純粋な関数で、都市ごとの計算（`cityOutput(state, cityId)`）を都市概要・内政画面の見込み表示と共有する。

1. **担当の補正**: 代官から商業・生産・成長の倍率、軍事担当から募兵・訓練の倍率を求める
2. **金**: 勢力ごとに、自勢力の都市の実効商業 × `GOLD_PER_MARKET` を合計して国庫に足す。所属する騎士の俸禄（`SALARY`。仮に一律）を引く
3. **物資と建設**: 実効生産を求める。建設中なら進捗に足し、`requiredSupplies` に届いたら完成（スロットに入れ、余りは備蓄へ）。建設中でなければ備蓄に足す
4. **兵士と練度**: 兵がいれば練度 +1（自然上昇）＋ 軍事担当の訓練。上限 `MAX_MORALE`
5. **人口**: 実効商業・代官・施設から成長量を求めて足す
6. **Tier**: 人口が閾値（5,000 / 15,000）を超えたら Tier を上げる（スロット 2 / 4 / 6）。出来事に記録する

実効値と補正（仮。定数は `src/game/economy/balance.ts` にまとめ、テストで値を固定しない）:

- 実効商業 = 基礎商業 × (1 + 代官の補正 + 施設の補正)、生産も同じ形
- 代官の補正: 商業は政治、生産は政治と知力、成長は魅力から。能力 50 で 0、100 で +25% 程度。性格タグの補正は表で持つ（M002 は 2〜3 個だけ）
- 軍事担当の訓練: 1人目は統率から +0〜+2/ターン、2人目以降は半分ずつ
- 人口の成長: 実効商業に比例し、人口が大きいほど伸び率が下がる（例: `population × 0.5% × 実効商業 / 400` に上限）
- 募兵: 1ターンに募兵できる上限 = 実効生産 × 5（`soldierPool` を置き換える）× 軍事担当・施設の補正。1人あたり金 `RECRUIT_GOLD`。新兵の練度は `RECRUIT_MORALE`（仮に 20）で、全体の練度は兵数の加重平均で下がる

### 兵の出入り

- 侵攻の予約で、部隊の兵数の合計を出発都市の `troops` から引く（予約の取消で戻す）。予約の兵数の上限は都市の兵数になる（`soldierPool` は使わない）
- 出撃は兵1あたり物資 `SORTIE_SUPPLIES`・金 `SORTIE_GOLD` を払う。足りなければ予約できない
- 戦後: 攻撃側の勝利なら兵は目標の都市へ入る（練度は兵数の加重平均で混ざる）、防衛側の勝利なら出発都市へ戻る。損耗は battle 側が部隊の残兵を返せるようになるまで反映しない（全数が戻る。M002-24 で確認）
- 占領した都市の元の兵・備蓄・施設はそのまま新しい所属の物になる（仮）
- 輸送: `transport(state, from, to, { troops, supplies })`。自勢力の街道でつながった都市へ即時に移す。練度は加重平均。画面は後続

### 担当と侵攻の兼ね合い

- 侵攻画面の騎士カードに担当（代官・軍事）のバッジを出す。担当の騎士も選べ、選ぶと「担当を外して出撃」と分かる表示にする
- 予約したときに担当を外し、予約に `releasedAssignments` として記録する。予約を取り消したら、その都市の担当が空いていれば戻す
- 騎士が都市を離れたら（入城・退却・在野）担当から外れる。戻った（帰還）騎士の担当は戻さない
- 担当の騎士が予約中かどうかは、内政画面でも「出撃予約中」と出す

### UI（norden-ui）

- **都市概要**（`CityCommandScreen` の都市情報ウィンドウ）: 人口と Tier、商業・生産（実効値と基礎値）、備蓄物資、兵数と練度、施設スロット（施設の画像・空き）、建設中の進捗、代官。農業の欄は消す
- **HUD**: 勢力の金（と次のターンの収支の見込み）。`DateBar` の横か中に足す
- **内政画面**（`DomesticScreen`）: 都市コマンドの「建設」「割当」から開く（同じ画面のタブ）
  - 建設: スロットの一覧（建設済み・建設中・空き）、建てられる施設の一覧（必要な物資・金・効果・完成までのターン数の見込み、建てられない理由）、着工・中止
  - 割当: 代官・軍事担当の欄と、都市の騎士の一覧（能力・担当中・予約中）。割り当てると見込みの補正が出る
- **募兵画面**（`RecruitScreen`）: 兵数を選び、金・兵数・練度の前後を出す
- **成長の演出**: 新しいターンに入って初めて都市概要を開いたとき、`lastEconomy` の `before` → `after` で数値をカウントアップし、増分（+120 など）を出す。施設の完成・Tier の上昇は短い通知にする。都市ごとに一度見たら出さない（見たかどうかはゲームの状態ではなくホストの UI の状態に持つ）
- 画面の追加は `norden-ui/docs/screens.md` の手順に従い、カタログ（デモ）にも載せる
