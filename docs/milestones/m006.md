# M006: 会話システム（norden-dialogue）

騎士の立ち絵・顔付きのセリフ・背景・BGM・効果音で、簡易なノベルゲームのような場面を演出する仕組みを作る。傭兵の雇用や探索のランダムイベントなどを、この会話シーンで表す。

会話シーンは「台本」と「流れ」の2つで書く。台本（セリフ・話し手・立ち絵・背景・音・選択肢の文言）は1シーンにつき1つの JSON で、手で調整しやすく、エディタでプレビューできる。流れ（分岐・条件・金や物資の増減・フラグ）は TypeScript で書き、ゲームの規則の関数（`hireMercenary` など）をそのまま呼ぶ。台本には分岐を入れない。

再生の仕組みとエディタはサブプロジェクト norden-dialogue に置く（norden-ui・norden-data に積むには大きいため）。シーンそのもの（台本と流れ）はゲームのデータなのでルートの `src/dialogue/` に置く。セリフのデータ（`src/data/voiceLines.json`）をルートに置いて norden-data で編集するのと同じ形。

M006 では仕組みとエディタを作り、傭兵の雇用を最初の会話シーンにする。ランダムイベントは登録と抽選の仕組みとサンプルのシーンまでで、ゲームの進行から呼ぶのは探索の実装のとき。

複数のセッションで進めるための作業メモを兼ねる。タスクを終えたらチェックを付け、決めたことは「決定事項」、セッションの記録は末尾の「作業ログ」に追記する。

## 完了条件（通しのデモ）

1. `norden-dialogue` で `npm run dev` するとエディタが開き、ルートの `src/dialogue/` のシーンが一覧に出る
2. シーンを選ぶと、台本のブロックが命令の列として並ぶ。話し手は騎士の名前と顔で出る（JSON では騎士 ID）
3. ブロックを選んで再生すると、画面下のメッセージウィンドウに顔付きのセリフが出て、立ち絵（左・中央・右）、背景、BGM、効果音が台本どおりに出る。背景の画像が無ければ仮のグラデーションで出る（エディタでは背景の名前も出る）
4. クリック・Enter・Space で文字送りし、表示途中なら全文を一度に出す。話している騎士の立ち絵が明るく、ほかは暗くなる
5. エディタでセリフの文言を直し、話し手を騎士の名前から選び直して保存すると、JSON が書き換わる（命令は1行に1つで、差分は直した行だけ）。開いているゲームにもそのまま反映される
6. VSCode で JSON を直接直すと、エディタにもそのまま反映される。JSON には補完が効く（`$schema`）。存在しない騎士 ID・背景・効果音・曲、宣言していない変数を書くと `npm test` が落ち、エディタにもエラーが出る
7. エディタの「通し再生」で、シーンの変数（傭兵など）を選んで流れごと再生できる。選択肢を選ぶと分岐し、終わると状態の変化（金・物資・フラグ・騎士の所属）が記録に出る。状態はゲームの初期状態から作る
8. ゲームで傭兵画面の「契約」を押すと、傭兵の雇用シーンが始まる。傭兵が登場して名乗り、契約金を示し、「契約する（n金貨）」「やめておく」を選ぶ。金が足りなければ「契約する」は押せず、理由が出る
9. 「契約する」を選ぶと効果音が鳴り、シーンが終わると金が減って、傭兵が都市の騎士一覧に加わる。「やめておく」なら何も変わらない。シーンが終わると BGM が戦略画面の曲に戻る
10. デバッグコンソールの `dialogue list` でシーンの一覧、`dialogue play <id> [変数=値…]` でシーンを再生できる。サンプルのランダムイベント（旅の商人）を再生すると、選択によって金と物資が変わり、フラグが立つ。もう一度再生すると、フラグを見て別のセリフになる。`flag list` でフラグを確かめる

## スコープ

含む:

- norden-dialogue（新しいリポジトリ・ルートのサブモジュール）: 台本の型と検査・JSON Schema、シーンの実行（`defineScene` と `ctx`）、プレイヤー（React の画面）、エディタ
- ルート: `GameState.flags`、`src/dialogue/`（シーンの登録・騎士と背景と音の提供・ゲームの画面への重ね方）、台本の検査のテスト
- 傭兵の雇用シーンと、傭兵画面の「契約」からのつなぎ込み
- ランダムイベントの登録と抽選の仕組み、サンプルのイベント（旅の商人）
- デバッグコンソールの `dialogue`・`flag`

含まない（後続のマイルストーン）:

- 探索と、探索からランダムイベントを呼ぶこと。放浪の騎士の登用のシーン
- 表情差分（騎士の画像が1人1枚のため）。カットイン（norden-ui の CutIn を呼ぶ命令）
- テキスト中の制御（途中の間・文字の速さ・色）
- オート・既読スキップ・バックログ
- エディタでの構造の編集（命令やブロックの追加・削除・並べ替え。M006 では JSON を手で直す）
- メッセージウィンドウ専用のデザイン（M006 は norden-ui の既存の枠を使う。必要なら別に作る）
- 背景の画像そのもの（置き場所と仮の表示だけ決める）
- 騎士ごとの口調に合わせたセリフの出し分け（傭兵の雇用シーンは全員同じ台本）

## 決定事項

### 構成

| 項目 | 決定 |
| --- | --- |
| リポジトリ | `sylx/norden-dialogue`。ルートのサブモジュール `norden-dialogue/`。GitHub Pages の公開はしない |
| パッケージ | 1つのパッケージ。`src/` が再生の仕組み（ルートが使う。`src/index.ts` から export）、`editor/` がエディタ（Vite のアプリ） |
| ルートからの使い方 | norden-ui と同じくソースをそのまま使う。ルートの `vite.config.ts` に alias `norden-dialogue` → `./norden-dialogue/src/index.ts` を足す |
| 単体での動作 | 求めない。エディタは親（nordencult）の `src/dialogue/`・`src/data/`・`src/assets/`・`src/audio/` を読む前提で、無いときの代わりは作らない |
| ゲームの知識 | norden-dialogue の `src/` は `GameState` を知らない（状態の型は型引数）。騎士・背景・音はルートが渡す（提供の関数） |
| UI の部品 | norden-ui の部品を使う（メッセージウィンドウの枠・選択肢のボタン） |

### 台本と流れの分担

| 項目 | 決定 |
| --- | --- |
| 置き場所 | `src/dialogue/<sceneId>.json`（台本）と `src/dialogue/<sceneId>.ts`（流れ）。ファイル名がシーンの id で、ルートのほかのファイルと同じく camelCase（`hireMercenary`） |
| 粒度 | 1シーンにつき1つの JSON |
| 台本 | タイトル・変数の宣言・ブロック（命令の列）・選択肢の文言。分岐や条件は持たない |
| 流れ | `defineScene(script, run)` の `run`。ブロックの再生・選択・状態の更新・フラグを書く |
| 型 | 流れは台本の JSON を `import` し、`defineScene` に渡す。`ctx.play` のブロック名、`ctx.choose` の選択肢の名前と戻り値（選択肢のキー）に JSON から型が付き、書き間違いは型検査で落ちる |
| 選択肢の戻り値 | 選んだ選択肢のキー（`'yes'` など）。並び順を変えても流れは壊れない |
| 選べない選択肢 | 条件は流れが持ち、`ctx.choose('hire', { disabled: { yes: '金貨が足りない' } })` で理由ごと渡す。押せないボタンに理由が出る |
| シーンの登録 | `src/dialogue/index.ts` の `SCENES`（id → シーン）。ゲームとエディタとデバッグコンソールはここから引く |

### 実行

| 項目 | 決定 |
| --- | --- |
| 状態の更新 | `ctx.state` はシーン用の写しで、`ctx.update(s => hireMercenary(s, …))` で更新する。シーンが終わったときに一度にゲームへ反映する |
| 規則の違反 | 流れの中で `GameRuleError` が出たらシーンを打ち切り、何も反映せずエラーを出す（通知の窓） |
| 中断 | プレイヤーはシーンを途中でやめられない。会話中は画面全体を覆い、ほかの操作を受けない。セーブの仕組みは今は無いが、作るときも会話中はセーブしない |
| 乱数 | `ctx.random`。ゲームでは `Math.random`、エディタでは種を決めた乱数。シーンの中で `Math.random` を使わない |
| 再現 | 選択の履歴と乱数の種があれば同じ進行になる。エディタは途中のブロックへ飛ぶとき、先頭から選択の履歴どおりに自動で流し直す |
| 変数 | `ctx.bind({ merc: id, price })` で台本の変数に値を入れる。以後の `play`・`choose` で使う。宣言（台本の `params`）と型が合わなければエラー |
| 終わったとき | 立ち絵と背景を片付け、BGM を今の画面の曲（`SCENE_BGM`）に戻す |

### フラグ

| 項目 | 決定 |
| --- | --- |
| 持ち方 | `GameState.flags: Readonly<Record<string, number \| boolean>>`。最初は空 |
| 名前 | `<シーン id>:<名前>`（`travelingMerchant:met`）。ほかのシーンのフラグも読める |
| 操作 | `src/game/flags.ts` の `flagOf(state, key)`・`setFlag(state, key, value)`。流れからは `ctx.update(s => setFlag(s, …))` |
| 画面 | 出さない。デバッグコンソールの `flag list`・`flag set` で見る・変える |

### 話し手と立ち絵

| 項目 | 決定 |
| --- | --- |
| 話し手の書き方 | 騎士 ID（`"001"`）か変数（`"$merc"`。値は騎士 ID）。JSON に名前は書かない。エディタは名前と顔で出し、名前から選ばせる |
| 名前だけの話し手 | `{ "name": "村人", "text": "…" }`。顔は出ない |
| 名前の差し替え | `{ "say": "$merc", "name": "???", "text": "…" }`。顔は出たまま、名前だけ変わる |
| 顔 | メッセージウィンドウの左に、騎士のスプライトの `faceRect` を出す |
| 立ち絵 | 騎士のスプライトのセル全体（512×768）。位置は左・中央・右の3つ |
| 話し手の強調 | 話している騎士の立ち絵は明るく、ほかの立ち絵は暗くする。命令は要らない |
| 騎士の提供 | ルートの `src/dialogue/cast.ts` が、騎士 ID から名前・シート画像・セルの範囲・顔の範囲を返す（`characterData.json`・`characterSprite.json`・`character-*.webp`）。ゲームとエディタで同じものを使う |

### 背景・音

| 項目 | 決定 |
| --- | --- |
| 背景の置き場所 | `src/assets/bg/<名前>.webp`。台本には名前だけ書く |
| 背景が無いとき | 名前から決まる色のグラデーションで出す。エディタでは名前も重ねて出す。検査では警告にとどめる（画像が揃うまで） |
| BGM | norden-synth の曲 id。ゲームの `playBgm` を使う |
| 効果音 | `src/assets/se/` の名前。ゲームの `playSe` を使う |
| 音の提供 | ルートの `src/dialogue/audio.ts` が `src/audio/` の関数を渡す。エディタも同じものを使う（エディタの vite の設定に norden-synth の alias を足す） |

### メッセージウィンドウ

| 項目 | 決定 |
| --- | --- |
| 見た目 | norden-ui の既存の枠を画面下に出す。専用のデザインは後で作る |
| 文字送り | クリック・Enter・Space。表示の途中なら全文を出し、出し切っていれば次へ |
| 文字の表示 | 1文字ずつ出す（速さは固定） |
| 選択肢 | メッセージウィンドウの上に縦に並べる。直前のセリフは残す |

### 検査

| 項目 | 決定 |
| --- | --- |
| 形の検査 | norden-dialogue の `validateScript(json)`。知らない命令・欠けた項目・宣言していない変数・使っていない宣言を返す |
| データとの照合 | ルートのテスト（`src/dialogue/scripts.test.ts`）で全シーンを検査し、騎士 ID・効果音・曲 id が実在することも確かめる。背景は警告だけ |
| エディタ | 同じ検査をかけ、エラーをブロックの横に出す |
| 補完 | norden-dialogue の `script.schema.json`（手で書く JSON Schema）。各台本の先頭に `"$schema"` を書き、VSCode の補完と検査を効かせる |

### エディタ

| 項目 | 決定 |
| --- | --- |
| 起動 | `norden-dialogue` で `npm run dev`（ポート 5176） |
| 読むもの | `import.meta.glob` で親の `src/dialogue/*.json`・`*.ts` と騎士のデータ・画像。JSON も TS も HMR で反映される |
| 画面 | 左にシーンの一覧、中央にブロックと命令の列、右（または上）にプレイヤー |
| ブロックの再生 | 選んだブロックだけを再生する。変数は宣言の型に合わせて仮の値を選ぶ（騎士は一覧から、数は入力） |
| 通し再生 | 流れごと再生する。状態はルートの `createInitialState()`。選択肢は手で選び、終わると状態の変化を記録に出す。選択の履歴から流し直せる |
| 編集できるもの | セリフの文言・話し手（騎士の名前から選ぶ）・名前だけの話し手の名前・地の文・選択肢の文言・タイトル。命令やブロックの追加・削除・並べ替えは JSON を手で直す |
| 保存 | エディタの dev サーバーのプラグイン（`PUT /api/dialogue/<sceneId>`）が JSON を書く。命令は1行に1つの決まった書式で書き出す（手で直すときの書式も同じ） |

### 傭兵の雇用

| 項目 | 決定 |
| --- | --- |
| 始まり方 | 傭兵画面の「契約」（今は押すとすぐ契約）で、雇用シーンを始める。norden-ui の傭兵画面は変えない（`onHire` の中身をルートで変える） |
| 傭兵画面 | シーンの間は傭兵画面の上に重ねる。終わったら傭兵画面に戻り、契約していれば「契約中」に出る |
| 中身 | 傭兵が登場して名乗り、契約金と月額を示し、「契約する（n金貨）」「やめておく」を選ぶ。契約すれば `hireMercenary` |
| 金が足りないとき | 「契約する」は押せず、`hireProblem` の理由を出す。傭兵画面で契約できない傭兵（選り好み）は今までどおり一覧で理由を出し、シーンは始まらない |
| 台本 | 全員同じ（`$merc` で名前と顔だけ変わる）。口調で出し分けるのは後続 |

### ランダムイベント

| 項目 | 決定 |
| --- | --- |
| 登録 | `src/dialogue/events.ts` の `RANDOM_EVENTS`。各イベントは id・シーン・起きる条件（状態と勢力から、シーンの変数か null を返す）・重み |
| 抽選 | `pickRandomEvent(state, factionId, random)`。条件を満たすイベントから重みで1つ選ぶ |
| ゲームから呼ぶこと | M006 ではしない（探索の実装のとき）。デバッグコンソールから再生して確かめる |
| サンプル | 旅の商人（`travelingMerchant`）。都市に商人が来て、金で物資を買うか断るかを選ぶ。前に会っていればセリフが変わる（フラグ） |

## 設計

### 台本（`src/dialogue/<sceneId>.json`）

```jsonc
{
  "$schema": "../../norden-dialogue/script.schema.json",
  "title": "傭兵を雇う",
  // 流れから渡す変数。型は character（騎士 ID）・city（都市 ID）・number・string
  "params": { "merc": "character", "price": "number", "monthly": "number" },
  "blocks": {
    "greet": [
      { "bg": "tavern", "fx": "fade" },
      { "bgm": "winter-council" },
      { "show": "$merc", "at": "right", "fx": "fade" },
      { "say": "$merc", "text": "{merc.name}だ。腕なら保証する。" },
      { "say": "$merc", "text": "前金で{price}金貨、あとは月に{monthly}金貨だ。" }
    ],
    "accept": [
      { "se": "coins" },
      { "say": "$merc", "text": "契約成立だ。" }
    ],
    "decline": [
      { "say": "$merc", "text": "気が変わったら声をかけてくれ。" },
      { "hide": "$merc", "fx": "fade" }
    ]
  },
  "choices": {
    "hire": { "options": { "yes": "契約する（{price}金貨）", "no": "やめておく" } }
  }
}
```

命令（1つのオブジェクトに1つ。先頭のキーで種類が決まる）:

| 命令 | 書き方 | 内容 |
| --- | --- | --- |
| `say` | `{ "say": "$merc" \| "001", "text": "…", "name"?: "…" }` | 顔付きのセリフ。`name` で名前だけ差し替える |
| `name` | `{ "name": "村人", "text": "…" }` | 顔の無い話し手 |
| `narrate` | `{ "narrate": "…" }` | 地の文 |
| `show` | `{ "show": "$merc", "at": "left" \| "center" \| "right", "fx"?: "fade" \| "slide" \| "none" }` | 立ち絵を出す。既定は `fade` |
| `hide` | `{ "hide": "$merc" \| "all", "fx"?: … }` | 立ち絵を消す |
| `move` | `{ "move": "$merc", "at": "center" }` | 立ち絵を動かす |
| `bg` | `{ "bg": "tavern" \| null, "fx"?: "fade" \| "cut" }` | 背景。`null` で黒 |
| `fade` | `{ "fade": "out" \| "in", "color"?: "black" \| "white", "ms"?: 600 }` | 画面全体の暗転・明転 |
| `shake` | `{ "shake": "small" \| "large" }` | 画面を揺らす |
| `flash` | `{ "flash": "white" \| "red" }` | 一瞬光らせる |
| `wait` | `{ "wait": 500 }` | 待つ（ミリ秒） |
| `bgm` | `{ "bgm": "曲 id" \| null }` | 曲を変える。`null` でフェードアウト |
| `se` | `{ "se": "coins" }` | 効果音 |

テキストの中: `{price}`（変数。数は `toLocaleString`）、`{merc.name}`（騎士・都市の名前）、`\n`（改行）。

ブロックの間で、背景・立ち絵・BGM はシーンの中なら引き継ぐ。

### 流れ（`src/dialogue/<sceneId>.ts`）

```ts
import script from './hireMercenary.json'

export const hireMercenaryScene = defineScene(script, async (ctx: SceneContext<typeof script, GameState>, { cityId, mercId }: { cityId: CityId; mercId: CharacterId }) => {
  const { fee, monthly } = contractPrice(ctx.state, ctx.state.activeFaction!, mercId)
  ctx.bind({ merc: mercId, price: fee, monthly })
  await ctx.play('greet')
  const problem = hireProblem(ctx.state, cityId, mercId)
  const pick = await ctx.choose('hire', { disabled: problem ? { yes: problem } : {} })
  if (pick === 'yes') {
    ctx.update((s) => hireMercenary(s, cityId, mercId))
    await ctx.play('accept')
  } else {
    await ctx.play('decline')
  }
})
```

norden-dialogue の `src/` が export するもの:

```ts
/** 台本の JSON の型（命令の union・ブロック・選択肢・変数の宣言） */
export type { Script, Command, ParamType }
export function validateScript(json: unknown): ScriptProblem[]

export interface SceneContext<S extends Script, State> {
  readonly state: State
  update(change: (state: State) => State): void
  bind(vars: Partial<Vars<S>>): void
  play(block: BlockName<S>): Promise<void>
  choose<C extends ChoiceName<S>>(choice: C, options?: { disabled?: Partial<Record<OptionKey<S, C>, string>> }): Promise<OptionKey<S, C>>
  random(): number
}
export function defineScene<S extends Script, State, P>(script: S, run: (ctx: SceneContext<S, State>, params: P) => Promise<void>): Scene<S, State, P>

/** シーンを流す。終わると最後の状態を返す（規則の違反なら投げる） */
export function runScene<State, P>(scene: Scene<Script, State, P>, params: P, init: { state: State; player: DialoguePlayer; random?: () => number }): Promise<State>

/** 画面（立ち絵・背景・メッセージウィンドウ・選択肢）。runScene が命令を渡す */
export function DialogueView(props: { player: DialoguePlayer; providers: DialogueProviders }): JSX.Element

/** ゲームが渡すもの: 騎士・都市の名前と画像、背景の URL、BGM と効果音 */
export interface DialogueProviders {
  character(id: string): { name: string; sheetUrl: string; sheet: { width: number; height: number }; cell: Rect; face: Rect } | undefined
  city(id: string): { name: string } | undefined
  background(name: string): string | undefined
  playBgm(songId: string | null): void
  playSe(name: string): void
}
```
