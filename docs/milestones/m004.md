# M004: 遺物（解体・修復・生産）

勢力が持つ遺物をアイテムボックスで管理し、研究＞遺物の画面で「解体して研究を進める」「自国で修復する」「法王府に金で修復してもらう」を選べるようにする。技術を研究すれば、遺物なしでの生産もできる。その一巡を最低限の実装で通す。設計の元は `docs/designs/research_and_artifact_and_so_on.md`。

遺物の入手は初期配布だけで、探索は扱わない。修復・生産した遺物の使い道（施設化・装備・召喚）も扱わない（どちらも後続のマイルストーン）。M004 の時点では、修復済みの遺物はアイテムボックスに並ぶだけになる。

複数のセッションで進めるための作業メモを兼ねる。タスクを終えたらチェックを付け、決めたことは「決定事項」、セッションの記録は末尾の「作業ログ」に追記する。

## 完了条件（通しのデモ）

1. 第1ターン。都市コマンドの「研究」＞「遺物」が押せ、自勢力のアイテムボックスが開く。初期配布の壊れた遺物が画像・名前・レアリティ・説明・できること（解体で得られる研究ポイント、修復の物資と金、法王府の修復の金）付きで並ぶ
2. 修復の技術が足りない遺物は、自国の修復が押せず、足りない技術が出る（例: 壊れたライフルは技術「ライフル」が要る）
3. 遺物を解体すると、確認のあとで遺物が消え、研究ポイントが研究中の技術に入る。届けばその場で完了し、完成の通知が出る
4. 研究先が無いときに解体すると、ポイントは宙に浮き、その場で技術画面が選択必須で開く。研究できる技術が残っていなければ解体できない（理由が出る）
5. 技術のいらない遺物（壊れたバリスタなど）か、技術を研究し終えた遺物を「修復」すると、開いている都市で修復が始まる。金を開始時に払い、遺物はボックスから「修復中」に移る。内政画面の建設の欄に進捗が出て、都市の生産が物資として入っていく
6. 内政画面の施設の横にある「遺物の修復」の枠からも、同じように修復を始められる。建設中の都市では、施設の建設も修復も始められない（理由が出る）
7. 一時停止・中止は建設と同じ。中止すると投入した物資の半分が都市に戻り、遺物は壊れたままボックスに戻る（開始時の金は戻らない）
8. 修復が終わると、ターンの初めに完成の通知（遺物の画像付き）が出て、修復済みの遺物がボックスに入る
9. 法王府に修復を頼むと、その場で金が減り、遺物は「法王府に依頼中」になる。1ヶ月後（次のターンの初め）に完成の通知が出て、修復済みになる。研究の技術はいらず、都市の生産も使わない
10. 技術「ライフルの生産」を研究し終えると、遺物画面と内政画面からライフルを生産できる（都市の条件はなし）。完成すると修復済みのライフルがボックスに増える。人工ドラゴンなども同じ。魔法の技術（雷魔法など）を研究し終えると、その魔導書も生産できる
11. 修復・生産の途中で都市が奪われると、それらは消滅する。投入した物資も開始時の金も戻らず、修復中の遺物も失われる。戦闘の結果の画面に、失われたものが出る（施設の建設は都市に付いたまま続く）
12. 勢力を滅ぼすと、その勢力のアイテムボックスの遺物が手に入る（デバッグ表示で確かめる）

## スコープ

含む:

- 遺物のマスターデータ（レアリティ・魔導書を含む）と norden-data の遺物エディタ、遺物の画像
- 勢力のアイテムボックスと、勢力ごとの初期配布
- 解体（研究ポイントの投入）
- 自国の修復・生産（建設と同じ枠で、都市の生産を物資として注ぐ）
- 法王府の修復（金だけ。1ヶ月後に届く）
- 法王府への献上のボタン（画面に出すだけ。処理は後続）
- 勢力の滅亡でのアイテムボックスの移動
- norden-ui: 遺物画面、内政画面の修復・生産、完成の通知
- デバッグ用の操作

含まない（後続のマイルストーン）:

- 探索（パーティー・ダンジョン）。戦闘の勝利・遺跡探索による研究ポイントも同じ
- 遺物の使い道: 施設化（`requiredRelic` の4施設は建てられないまま）、騎士の装備、召喚部隊
- 法王府の友好度と弾圧。修復を頼んでも友好度は持たない
- 法王府への献上の処理
- 知力による装備の制限
- CPU の遺物の操作（解体・修復・生産・法王府への依頼）

## 決定事項

| 項目 | 決定 |
| --- | --- |
| 遺物の入手 | M004 では初期配布だけ。`factionData.json` の `relics`（`{ relicId, repaired }` の配列。`RelicItem` と同じ形で、同じものを複数持てる）に書き、書いた状態でボックスに入る。デバッグ操作でも足せる。探索は後続で入手経路として足す |
| アイテムボックス | 勢力ごとに1つ（`GameState.relics`）。都市には置かない。容量の上限は無い |
| 遺物の持ち方 | 1つずつ別のもの（`RelicItem`）として持つ。後続の装備で「誰が装備しているか」を1点ごとに持つため |
| 遺物の種別 | 修復済みの使い道を `Relic.use`（`building`・`equipment`・`summon`）に持つ。M004 では画面の表示だけに使う |
| レアリティ | マスターに持つ（`Relic.rarity`。S・A・B・C）。M004 では画面の表示とエディタの編集だけに使い、後続の探索の抽選で使う |
| 遺物の名前 | 壊れた状態の名前（壊れたライフル・ドラゴンの卵）と、修復済みの名前（ライフル・ドラゴン）を別に持つ |
| 魔導書 | 遺物の生産に入れる。技術で解放される魔法ごとに1種類（雷・火・水・土・天体の5種類）。使い道は装備。壊れた状態を持たないので `brokenName`・`dismantlePoints`・`repair` を省略し、解体も修復もできない。初期配布は修復済みだけ。基礎魔法のサンダーフォールに魔導書は無い |
| 遺物の画像 | 技術と同じ大きさ（256×384）のセルのスプライト画像 `src/assets/relics.webp`。壊れた状態と修復済みで画像を分ける（`Relic.brokenSprite`・`Relic.sprite`）。修復中・依頼中は壊れた状態の画像を出す。壊れた状態が無い魔導書は `sprite` だけ。元画像の扱いは技術と同じ（`norden-data/relics/sources/` はコミットしない） |
| 解体できるもの | 壊れた遺物だけ。修復済みの遺物は解体できない。すぐに実行され、取り消せない（画面で確認を出す） |
| 解体の研究ポイント | 遺物ごとの値（`Relic.dismantlePoints`）。系統の割増は付かない。研究中の技術に入り、届いたらその場で完了にする（通知 `TechCompleted`。余りは `carry`）。研究先の無いときは `carry` に入る。処理は「宙に浮いたポイント」の入れ方（`setResearch`）と共有する |
| 研究先が無いときの解体 | 解体のあと、その場で技術画面を選択必須で開く（遺物画面の上に積む） |
| 研究できる技術が無いときの解体 | 解体できない。遺物を失うだけになるため。設計資料の「研究ポイントは消滅する」は、解体には当てはめない |
| 修復の条件 | 遺物ごとの技術（`Relic.repair.tech`）を研究し終えていること。省略なら技術はいらない（バリスタ・魔導台） |
| 修復の費用 | 遺物ごとの物資と金（`Relic.repair`）。金は建設と同じく開始時に勢力の国庫から払い、物資は都市の生産を毎ターン注ぐ |
| 修復・生産の枠 | 都市の建設の枠（`CityState.construction`）を共有する。施設の建設・修復・生産のうち、都市ごとに同時に1つ。建設の施設の枠（スロット）は使わない |
| 修復を始める場所 | 遺物画面と内政画面の「遺物の修復」の枠の両方。遺物画面では、開いている都市で修復する |
| 内政画面の遺物の枠 | 施設の横に区切り線を挟んで「遺物の修復」の枠を置く。空きの枠を押すと、右の欄に修復・生産できる遺物だけが出る。進行中の修復・生産もこの枠に出す。施設のスロットにも「追加できる施設」にも遺物を混ぜない。都市の情報でも施設の一覧とは別の欄に出す |
| 修復中の遺物 | 始めるとボックスから抜け、`construction` に移る。ボックスの画面には、都市の `construction` から「修復中（都市名）」として出す |
| 修復・生産の一時停止と中止 | 建設と同じ。中止は投入した物資の半分が都市に戻り、開始時の金は戻らない。修復の中止なら遺物は壊れたままボックスに戻る。生産の中止なら何も残らない |
| 修復・生産の余り | 建設と同じ。完成したターンの余りの物資は都市の備蓄に入る |
| 都市が奪われたとき | 施設の建設と異なり、修復・生産は消滅する（`construction` が null になる）。中止と異なり何も戻らない: 投入した物資・開始時の金は失われ、修復中の遺物も失われる。奪った勢力の手にも入らない。戦闘の結果に失われたものを出す（`BattleReport.lostRelicWork`） |
| 生産の条件 | 遺物ごとの技術（`Relic.production.tech`）を研究し終えていること。それだけ |
| 銃器工廠 | 没。設計資料の「銃器工廠が建設可能になる」はやめ、技術の条件を満たせばどの都市でも生産できる |
| 生産の費用と完成品 | 遺物ごとの物資と金（`Relic.production`）。遺物はいらない。完成品は修復済みの遺物としてボックスに入る。生産の無い遺物（バリスタ・魔導台）は `production` を省略する |
| 技術の文言 | `techData.json` の「壊れたライフルの修復」などの `etc` はそのまま。実際の判定は遺物の `repair.tech`・`production.tech` が持つ |
| 法王府の修復 | 頼むとその場で金が減り、1ヶ月後（次の内政処理）に修復済みになる。技術も都市の生産もいらず、同じターンに何度でも頼める。修復中の遺物には頼めない |
| 法王府に依頼中の遺物 | ボックスに入ったまま（`RelicItem.papalRepair`）で、解体も修復もできない。取り消せず、金も戻らない。都市を奪われても影響はない。勢力が滅びれば、依頼中のまま滅ぼした勢力へ移り、1ヶ月後に修復済みになる。依頼のあとで法王府が滅んでも届く |
| 法王府の修復の金 | `(repair.gold + repair.supplies) × PAPAL_REPAIR_RATE`（仮に 1.5）。端数は切り上げ。遺物ごとの値は持たない |
| 法王府の修復の代金 | 法王府の勢力（`sede`）の国庫に入る |
| 法王府に頼めないとき | 自勢力が法王府のとき、法王府が滅んでいるとき、金が足りないとき（理由を出す）。友好度は持たない |
| 法王府への献上 | 壊れた遺物と修復済みの遺物を法王府に献上でき、友好度が上がる（設計資料）。M004 では遺物画面に「法王府に献上」のボタンを出すだけで、押せないようにする（遺物が消えるだけになるのを避ける）。修復中・依頼中の遺物には出さない |
| 勢力の滅亡 | アイテムボックスの遺物はすべて、滅ぼした勢力のボックスへ移る |
| CPU | 遺物を操作しない。初期配布の遺物は持ったままになり、滅ぼせば手に入る |
| 中立の都市 | ボックスが無いので遺物を持たない。修復も生産もできない |
| 施設化（後続） | 修復済みの遺物を消費して建てる。修復済みの遺物があると「建てられる施設」に出て、通常の建設（物資・金・施設の枠）で建て、建て始めるときに遺物を1つ消費する。`requiredRelic` の「○○の設計図」は修復済みの遺物の id に読み替える。M004 では方針だけ決め、データも判定も変えない |
| 情報＞遺物 | 都市コマンドの「情報」＞「遺物」（`relicInfo`）は押せないまま。使い道のあとで決める |

/** 修復または生産の費用 */

  /** 都市の生産を注ぐ物資 */
  supplies: number
  /** 始めるときに国庫から払う金 */

interface Relic {
  id: string
  /** 修復済みの名前（ライフル、ドラゴン） */
  name: string
  /** 壊れた状態の名前（壊れたライフル、ドラゴンの卵）。省略: 壊れた状態が無い（魔導書） */

### 遺物の処理（`src/game/relics/`）

純粋な関数。画面の見込みと共有する:

- `relicItemView`: 遺物1つの表示に要る情報をまとめる問い合わせ。解体の研究ポイント・修復の費用・法王府の金と、できない理由
- `dismantleProblem(state, factionId, itemId)`・`dismantleRelic(state, factionId, itemId)`: 解体
- `repairProblem(state, cityId, itemId)`・`startRelicRepair(state, cityId, itemId)`: 自国の修復を始める
- `productionProblem(state, cityId, relicId)`・`startRelicProduction(state, cityId, relicId)`: 生産を始める
- `papalRepairProblem(state, factionId, itemId)`・`papalRepairCost(relic)`・`requestPapalRepair(state, factionId, itemId)`: 法王府への依頼。金を払い、遺物を依頼中にする
- `relicWorks(state, factionId)`: 勢力の都市で進行中の修復・生産の一覧（ボックスの画面の「修復中」）

研究の側（`src/game/research/`）:

- `addResearchPoints(state, factionId, points)`: ポイントを研究中の技術に入れ、届けば完了にする。研究先が無ければ `carry` に入れる。`setResearch` の投入と共有する

建設の側（`src/game/economy/`）:

- `cancelConstruction`: 修復の中止なら、遺物を壊れた状態で都市の勢力のボックスに戻す
- `runEconomy`: 完成したら `work` で分け、遺物なら都市の勢力のボックスに修復済みの遺物を足し、プレイヤーの勢力なら `RelicCompleted` を積む。法王府に依頼中の遺物も修復済みにして、同じく積む

戦闘の解決（`resolveBattle`）で都市が奪われたとき、`construction` の `work` が修復・生産なら `construction` を null にし、`BattleReport.lostRelicWork` に入れる。施設の建設なら今までどおり残す。

滅亡の処理（`destroyFaction`）で、アイテムボックスを `by` の勢力へ移す。

定数は `src/game/economy/balance.ts` に足す（`PAPAL_REPAIR_RATE`）。

### UI（norden-ui）

- **遺物画面**（`RelicScreen`）: 全画面のウィンドウ（`WindowFrame`）。都市コマンドの「研究」＞「遺物」で開く。左に遺物の一覧（画像と名前。壊れた・修復中（都市名）・法王府に依頼中・修復済みで描き分ける）、右に選んだ遺物の詳細（画像・レアリティ・説明・使い道・操作）
  - 壊れた遺物の操作: 「解体（研究 +n）」（確認あり）、「修復（物資・金）」、「法王府に依頼（金）」。できないものは押せず、理由を出す
  - 壊れた遺物と修復済みの遺物に「法王府に献上」のボタンを出す（M004 では押せない）
  - 一覧の下または別の欄に、生産できる遺物（技術の条件を満たしたもの）と「生産（物資・金）」
  - 上部に開いている都市の建設の枠の状態（空き・進行中のもの）と国庫の金
  - 修復済みの遺物は「使い道はまだありません」のように出す
- **内政画面**: 施設の横に、区切り線を挟んで「遺物の修復」の枠を置く。空きの枠から右の欄に修復・生産できる遺物を開き、進行中の修復・生産（`ConstructionView`）もこの枠に出す。施設の一覧には混ぜない
- **完成の通知**: `relicCompleted` を `events` の通知にし、`EventScreen` の `picture` に遺物の画像を出す
- **戦闘の結果の画面**: `BattleReport.lostRelicWork` があれば、失われた修復・生産を出す
- 画面の追加は `norden-ui/docs/screens.md` の手順に従い、カタログ（デモ）にも載せる

## 未決事項・後続の候補

- 探索による遺物の入手。魔導書を探索で手に入れるときは修復済みで入れる
- 遺物の使い道: 施設化（方針は決定事項のとおり）、装備、召喚
- 法王府の友好度。依頼と献上で上がる分と、弾圧との関係
- 献上の処理（遺物を失う・レアリティで友好度の上がり方を変えるか・法王府が滅んだとき）
- CPU の遺物の扱い
- 修復済みの遺物の解体（使い道ができたあとで要るか決める）
- 遺物の本番の画像（`src/assets/relics.webp` はいま仮。`norden-data/relics/sources/relics01.webp` もコミットしない仮の元画像）

- 万色の魔導書の使い道（いまは雷・火・水・土の術式をまとめた書という説明だけで、効果は未定）
- 遺物の仮画像の文字が古い名前のまま（停止したゴーレム・ベヒーモスの化石・魔導書5種）。万色の魔導書は画像なし
- 強弓術・斉射戦法の画像が大砲の絵のまま（`research01.webp` に弓の絵が無い）
- 要塞砲の遺物の画像が大砲の仮画像のまま
