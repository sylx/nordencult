# 効果音

ここに置いた `<名前>.ogg`（`.mp3`・`.wav` も可）が、効果音 `<名前>` になります（`src/audio/se.ts`）。置くだけで読み込まれ、ビルドにも入ります。

| 名前 | 鳴る場面 |
| --- | --- |
| `click` | UI のクリック（ボタン・タブ・選択肢・チェックボックス、戦闘の行動メニューと配備の一覧） |
| `whoosh` | 拠点の切り替え（地図で別の拠点を選ぶ・前後の拠点へ送る・命令の一覧から拠点を開く） |
| `complete` | 技術の研究完了（その通知が出る時） |
| `coins` | 傭兵の契約 |

ファイルが無い効果音は鳴らず、初めて鳴らそうとした時にコンソールに警告が出ます。
