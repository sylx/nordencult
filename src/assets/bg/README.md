# 会話の背景

ここに置いた `<名前>.webp` が、会話シーンの台本の背景 `<名前>` になります（`{ "bg": "tavern" }`。`src/dialogue/cast.ts`）。置くだけで読み込まれ、ビルドにも入ります。大きさはイベント通知のカット（`norden-ui/src/assets/cut/`）と同じ 1680×720 で作ります（違う比のものは中央で切り抜かれます）。

画像の無い背景は、名前から決まる色の仮のグラデーションで出ます（norden-dialogue のエディタでは名前も重ねて出ます）。`npm test` の台本の検査では警告にとどまります。

| 名前 | 場面 |
| --- | --- |
| `tavern` | 酒場（傭兵の雇用） |
| `market` | 都市の市場（旅の商人） |
